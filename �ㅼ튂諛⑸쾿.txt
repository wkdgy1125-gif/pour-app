타설집계 앱 설치 방법
========================

이 폴더는 "설치형 웹앱(PWA)"입니다. 인터넷 주소(https)에 한 번 올려두면
휴대폰·PC 어디서나 그 주소로 들어가 "앱 설치 / 홈 화면에 추가"를 할 수 있습니다.
설치 후에는 아이콘으로 실행되고, 주소창 없는 전체 화면으로 열리며,
한 번 실행한 뒤에는 인터넷이 없어도 동작합니다.

※ 파일을 휴대폰에 복사해서 직접 여는 방식으로는 앱 설치가 되지 않습니다.
  (앱 설치는 https 주소에서만 가능한 브라우저 규칙)


1단계. 무료로 인터넷에 올리기 (GitHub Pages, 약 5분)
--------------------------------------------------
1) github.com 에서 무료 계정을 만들고 로그인
2) 오른쪽 위 [+] → New repository → 이름 예: pour-app → Public → Create
3) "uploading an existing file" 클릭 → 이 폴더의 파일 전부를 끌어다 놓기
   (index.html, manifest.webmanifest, sw.js, icon-*.png, apple-touch-icon.png)
   → Commit changes
4) 저장소의 Settings → Pages → Branch: main / (root) → Save
5) 1~2분 뒤 https://<내아이디>.github.io/pour-app/ 주소로 열림

※ Netlify, Cloudflare Pages 같은 다른 무료 호스팅에 폴더째 올려도 됩니다.


2단계. 휴대폰에 설치
--------------------
[안드로이드 - 크롬]
  위 주소 접속 → 화면의 [앱 설치] 버튼, 또는 메뉴(⋮) → "앱 설치"/"홈 화면에 추가"

[아이폰 - 사파리]
  위 주소 접속 → 아래 공유 버튼(□↑) → "홈 화면에 추가"

[PC - 크롬/엣지]
  주소창 오른쪽의 설치 아이콘, 또는 화면의 [앱 설치] 버튼


업데이트할 때
-------------
GitHub 저장소의 index.html을 새 파일로 바꿔 올리면,
앱을 다음에 인터넷 연결된 상태로 열 때 자동으로 새 버전이 적용됩니다.


플레이스토어용 안드로이드 앱(APK/AAB)이 필요하면
-------------------------------------------------
1단계로 올린 주소를 pwabuilder.com 에 입력하면
이 웹앱을 감싼 안드로이드 패키지를 만들 수 있습니다.


데이터 저장 관련
----------------
- 작업 내용은 그 기기 안에 자동 저장됩니다(기기끼리 자동 공유는 안 됨).
- 휴대폰↔PC로 옮길 때는 [저장]으로 프로젝트 파일(.json)을 받아
  다른 기기에서 [열기]로 불러오세요.
- 앱을 삭제하면 그 기기에 저장된 작업도 지워지니, 중요한 작업은 [저장]해 두세요.
